# PPF UX v1.3.1 · Workspace Header Polish

## Objetivo
Unificar la geometría visual del encabezado de Client Workspace en sus estados vacío y activo.

## Cambios
- El botón **Cerrar cliente** queda integrado visualmente dentro del selector, junto a la flecha del desplegable.
- El estado vacío y el estado con cliente mantienen la misma anchura y alineación.
- **Nueva sesión** ya no invade ni se monta sobre el selector.
- El botón permanece oculto cuando no existe cliente activo.
- Se conserva el tooltip accesible **Cerrar cliente** y la navegación por teclado.
- En móvil, selector y botón Nueva sesión se apilan de forma limpia.
- El botón Nueva sesión deshabilitado tiene un estado visual claro.

## Compatibilidad
Conserva PPF UX v1.1, v1.2 y v1.3.
