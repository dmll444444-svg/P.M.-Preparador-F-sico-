# Gráfica PRO v3.2 · Predictive Intelligence

## Incorporado
- Proyección lineal explicable por categoría usando hasta ocho microciclos.
- Nivel de confianza basado en longitud del histórico, continuidad y ajuste de tendencia.
- Stability Index del proceso.
- Priority Radar: Correcto, Vigilar o Revisar.
- Coach Timeline con progresión, reducción y estabilidad.
- API global `PPFPredictiveIntelligence`.

## Criterio metodológico
Las proyecciones indican dirección estructural probable si el patrón continúa. No predicen rendimiento, fatiga, lesión ni respuesta fisiológica.
