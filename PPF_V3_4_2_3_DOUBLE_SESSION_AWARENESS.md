# PPF v3.4.2.3 · Double Session Awareness

Mejora UX de notificación de microciclo.

- Mantiene una sola notificación agrupada por micro.
- Si existe doble sesión, muestra el día exacto.
- Muestra las sesiones implicadas con numeración funcional/canónica.
- Ejemplo: `⚡ miércoles 19 de agosto · 8.2 + 8.3`.
- Si hay varios días dobles, muestra todos.
- No modifica Deep Clone, Date Planner, Agenda PRO ni Session Lifecycle.
