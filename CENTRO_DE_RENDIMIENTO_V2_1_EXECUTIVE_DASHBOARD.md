# Centro de Rendimiento v2.1.0 · Executive Dashboard

## Cambios
- Panel de mando ejecutivo situado bajo el Executive Performance Header.
- Resumen compacto de Performance Score, Coach Score, Stability Index y nivel de atención.
- Cambios relevantes entre los microciclos seleccionados: sesiones, series y tonelaje.
- Estado por áreas: carga, distribución, estabilidad y coherencia.
- Alertas ejecutivas priorizadas, con un máximo de tres señales visibles.
- Accesos rápidos a comparación, radar, KPIs, inteligencia e insights.
- Diseño responsive para escritorio, tablet y móvil.

## Compatibilidad
No se modifican las APIs internas ni el modelo de datos existente.
