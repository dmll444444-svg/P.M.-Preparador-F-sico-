# Gráfica PRO v4 · Performance Intelligence

Capa final de síntesis ejecutiva para interpretar el proceso en segundos.

## Incluye
- Lectura ejecutiva priorizada.
- Coach Score, Stability Index e histórico útil.
- Recomendación principal y dirección probable.
- Decisiones a considerar.
- Detalle avanzado bajo demanda mediante divulgación progresiva.
- API reutilizable `PPFPerformanceIntelligence`.

## Principio metodológico
El sistema interpreta estructura y continuidad de la planificación. No diagnostica rendimiento, fatiga, lesión ni sustituye el criterio profesional.
