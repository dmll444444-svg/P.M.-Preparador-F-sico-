# Creación de Sesiones PRO v2.1 — Unidades inteligentes

- Se amplía el selector Unidad de todos los ejercicios de Sesión Principal.
- Unidades disponibles: Kg, %, BW, m, s, min, rep, cal y m/s.
- Las opciones aparecen agrupadas por Carga, Distancia, Tiempo, Otras y Velocidad.
- Al cambiar el Tipo se propone una unidad lógica: fuerza y movimientos olímpicos → Kg; core, pliometría y lanzamientos → rep; Tarea de Campo → m.
- La unidad siempre puede modificarse manualmente después.
- Las unidades históricas no incluidas en la lista se conservan al editar sesiones antiguas.
- Se añade Tarea de Campo a los tipos de Sesión Principal.
- No se altera ninguna sesión ya guardada ni la sincronización con Supabase.
