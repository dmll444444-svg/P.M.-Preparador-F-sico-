# Biblioteca PRO v2.1 — Render definitivo

- Un único array normalizado alimenta contador y tarjetas.
- Se limpia el contenedor antes de cada renderizado.
- Compatibilidad con campos antiguos: name/nombre, type/tipo, description/descripcion y url/videoUrl/video/enlace.
- Cada tarjeta se renderiza de forma aislada para que un registro irregular no bloquee el catálogo.
- Acciones Editar y Eliminar mediante delegación de eventos, sin JavaScript inline.
- No se modifican ejercicios, IDs, categorías, URLs ni integración con Sesiones PRO.
