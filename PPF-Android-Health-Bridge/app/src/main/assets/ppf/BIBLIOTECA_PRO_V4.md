# Biblioteca PRO v4

## KPI útil de biblioteca

Se sustituye el KPI general **Archivos guardados** por **Cobertura de vídeo**.

El KPI muestra:

- Porcentaje de ejercicios con URL de vídeo.
- Número de ejercicios con vídeo.
- Número de ejercicios sin vídeo.

La biblioteca, los tipos, las categorías, las URLs y la integración con Sesiones PRO permanecen intactos.
