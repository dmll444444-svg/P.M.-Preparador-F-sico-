# GRAFICA PRO v2.2.1 · Meaningful Comparison

## Objetivo
Separar el contexto de planificación de las métricas que sí permiten analizar carga y distribución.

## Cambios
- La métrica **Sesiones** deja de mostrarse mediante barras.
- Se presenta como dato contextual compacto: `M1: 2 → M2: 3 · +1 sesión`.
- Los contadores Aumentan, Disminuyen y Estables ya no incluyen sesiones.
- La mayor variación se calcula únicamente con series, ejercicios, tonelaje y categorías.
- Las barras comienzan directamente con métricas relevantes para la toma de decisiones.
- Se mantiene intacta la fuente de verdad y la selección de microciclos.
