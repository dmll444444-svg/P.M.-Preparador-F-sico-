# NCI Subsesiones v1

- Numeración visible por microciclo y orden: 15.1, 15.2, 15.3.
- Botones Antes/Después en Creación de sesiones para fijar el orden oficial.
- Cliente Web/PWA recibe y ordena las sesiones según subsessionOrder.
- Tipos visuales de sesión con iconos: Gimnasio, Campo, Recuperación, Test, Competición y Otra.
- Notificaciones actualizan el número visible al reordenar.
- IDs y números internos históricos se conservan para compatibilidad.
