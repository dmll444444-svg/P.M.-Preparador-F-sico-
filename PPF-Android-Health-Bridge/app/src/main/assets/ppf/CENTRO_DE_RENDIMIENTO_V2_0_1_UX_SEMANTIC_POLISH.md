# Centro de Rendimiento v2.0.1 · UX & Semantic Polish

## Cambios
- Eliminado el encabezado duplicado del deportista.
- Comparación activa integrada en el Executive Performance Header.
- Cabecera compactada para reducir desplazamiento vertical.
- El motor diferencia tonelaje y número de series.
- Cuando un micro tiene actividad pero 0 kg, se muestra una advertencia de datos incompletos y no se clasifica automáticamente como descarga.
- Panel ejecutivo reorganizado en diagnóstico, motivo y acción recomendada.
- Performance Score conserva la tendencia basada en series cuando el tonelaje no es comparable.

## Compatibilidad
No se modifican datos persistidos ni las APIs internas PPFCoachIntelligence, PPFPredictiveIntelligence y PPFPerformanceIntelligence.
