# PPF · FASE 2.4 · Library Running Integration

Integración de Sesiones Carrera como cuarta categoría nativa de Biblioteca PRO.

## Cambios
- Nueva categoría seleccionable: `🏃 Sesiones Carrera`.
- Nuevo contador de Carrera en Biblioteca PRO y KPI superior.
- Biblioteca PRO pasa a reflejar 4 categorías configuradas.
- Nuevo filtro `Carrera` en el catálogo.
- Icono de corredor para ejercicios cuya categoría principal sea Sesiones Carrera.
- Tipos sugeridos de carrera: Carrera continua, Intervalos, Sprint, Recuperación, Técnica de carrera, Cuestas y Fartlek.
- El constructor de Sesiones Carrera consume la biblioteca mediante autocompletado, igual que Movilidad, Activación y Principal.
- Se mantiene la multiasignación: un ejercicio puede pertenecer simultáneamente a Carrera y a cualquier otra categoría.

## Sin cambios
No se modifica el guardado de sesiones, Supabase, sincronización, ordenación, KPIs de rendimiento ni Smart Edit Entry.
