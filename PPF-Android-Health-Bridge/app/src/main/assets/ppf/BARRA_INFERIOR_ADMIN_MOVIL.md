# Barra inferior fija del Admin móvil

## Navegación principal
- Inicio
- Pacientes
- Sesiones (acción central destacada)
- Usuarios
- Más

## Panel Más
Incluye Biblioteca, Periodicidad, Gráfica PRO, Valoraciones, Sistema y cierre de sesión.

La barra solo se activa hasta 820 px. En escritorio se conserva el menú lateral completo. Todas las rutas utilizan el mismo `renderSection`, por lo que no se duplica la lógica de navegación.
