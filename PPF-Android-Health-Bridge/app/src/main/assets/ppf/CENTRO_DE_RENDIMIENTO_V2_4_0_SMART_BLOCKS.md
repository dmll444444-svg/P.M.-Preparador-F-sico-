# Centro de Rendimiento v2.4.0 · Smart Blocks

Cierre de Block Comparison Intelligence.

## Implementado
- Comparaciones inteligentes generadas a partir del historial real del deportista.
- Evolución reciente: últimos micros frente al bloque inmediatamente anterior.
- Inicio frente a actualidad.
- Mayor carga frente a mayor estabilidad.
- Contraste de densidad de trabajo.
- Aplicación automática de nombres, micros y modo Bloques con un solo clic.
- Exclusividad garantizada entre Bloque A y Bloque B.
- Integración con KPIs, Radar, Timeline y motores de inteligencia existentes.
- Diseño responsive y estados de datos insuficientes.
