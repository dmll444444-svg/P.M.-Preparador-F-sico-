# PPF PRO v2.5.0.1.2 · Workspace Navigator

## Implementación

- El botón flotante adopta formato mini-KPI con etiqueta visible.
- Estado normal: `☰ Menú`.
- Estado informativo en hover/foco: `☰ Menú · Sección actual`.
- Estado abierto: `✕ Cerrar`.
- El contexto se sincroniza con Inicio, Paciente, Usuarios, Biblioteca, Creación sesiones, Agenda PRO, Periodicidad, Centro de Rendimiento, Valoraciones y Sistema.
- Transición breve al cambiar de sección.
- Etiquetas ARIA y `title` contextuales.
- En móvil mantiene una versión compacta `☰ Menú` / `✕ Cerrar` para no cubrir contenido.
- Sin cambios en la navegación, el drawer ni los contratos de datos existentes.
