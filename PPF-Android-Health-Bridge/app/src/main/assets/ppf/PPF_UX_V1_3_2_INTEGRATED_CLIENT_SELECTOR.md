# PPF UX v1.3.2 · Integrated Client Selector

## Corrección
- Selector de cliente y cierre forman un único componente visual.
- Flecha personalizada y botón de cierre integrado antes de la flecha.
- Nueva sesión conserva una anchura estable y no se superpone.
- El layout se adapta a escritorio, tablet y móvil.
- Se mantiene el tooltip «Cerrar cliente», la navegación por teclado y la limpieza completa del Workspace.

## Compatibilidad
Incluye PPF UX v1.1, v1.2, v1.3 y v1.3.1.
