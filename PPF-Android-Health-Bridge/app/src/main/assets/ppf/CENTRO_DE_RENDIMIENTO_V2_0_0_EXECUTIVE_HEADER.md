# Centro de Rendimiento v2.0.0

## Executive Performance Header

Primera entrega funcional de Centro de Rendimiento v2.

### Incorporado
- Performance Score global combinando Coach Score y Stability Index.
- Estado visual del deportista: estable, atención o revisión prioritaria.
- Contexto ejecutivo de la comparación activa.
- Tendencia de carga entre microciclos.
- Prioridad automática del entrenador.
- Decisión práctica contextual.
- Diseño responsive para escritorio, tablet y móvil.

### Compatibilidad
No se modifican los datos, cálculos almacenados ni las APIs internas existentes. La nueva capa reutiliza Coach Intelligence y Predictive Intelligence.
