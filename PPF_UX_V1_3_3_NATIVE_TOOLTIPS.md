# PPF UX v1.3.3 · Native Tooltips

Pulido final del selector integrado de Client Workspace.

- Tooltip visual propio **«Cerrar cliente»** al pasar el puntero o enfocar con teclado.
- Sustituye cualquier dependencia del tooltip nativo del navegador.
- Aparición suave con un breve retardo para evitar activaciones accidentales.
- Fondo oscuro, borde verde PPF, sombra y tipografía coherentes con Agenda PRO.
- El tooltip no se muestra en dispositivos táctiles o pantallas móviles.
- Se conserva `aria-label="Cerrar cliente"` para accesibilidad.
- Se corrige el recorte provocado por el contenedor del selector integrado.
